# Internationalization (i18n)

## Supported Languages
- Vietnamese (vi) - Default
- English (en) - Planned

## Adding Translations
1. Create file: app/lib/i18n/[lang].ts
2. Export translation object
3. Follow existing key structure

## Key Structure
common.* - Common UI strings
nav.* - Navigation items
scan.* - Scan page
quiz.* - Quiz page
dashboard.* - Dashboard
admin.* - Admin panel
error.* - Error messages

## Usage
import { t } from '@/app/lib/i18n'
<p>{t('common.welcome')}</p>docs: add internationalization guide
