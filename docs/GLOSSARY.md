# Glossary

- **Phishing**: Fraudulent attempt to obtain sensitive information
- **Scam**: Deceptive scheme to defraud
- **TLD**: Top-Level Domain (.com, .org, etc.)
- **Heuristic**: Rule-based analysis method
- **Blocklist**: List of known malicious domains
- **Whitelist**: List of verified safe domains
- **Threat Feed**: External source of threat intelligence
- **WHOIS**: Protocol for querying domain registration info
- **SSL**: Secure Sockets Layer encryption
- **CSRF**: Cross-Site Request Forgery
- **XSS**: Cross-Site Scripting
