# Quiz System Documentation

## Overview
The quiz system educates users about online scams through interactive questions.

## Categories
- Phishing
- Investment scams
- Romance scams
- Job scams
- Prize/lottery scams
- Impersonation
- Cryptocurrency scams

## Difficulty Levels
- Easy: Basic recognition
- Medium: Pattern analysis
- Hard: Advanced scenarios

## Scoring
- Correct answer: +10 points
- Streak bonus: +5 per consecutive correct
- Time bonus: +3 if answered within 10s
- Perfect score: 2x multiplier
